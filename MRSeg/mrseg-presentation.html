Motivation & Proposed Method

Problem
01 Existing methods improve where modalities interact, but apply the same adapter subspace to every image–text pair regardless of case.
02 Different cases demand different adaptation: a small unilateral opacity needs local texture sensitivity; widespread infection needs broader spatial context.
03 Granularity mismatch: clinical descriptions are semantic/regional, yet segmentation must be pixel-level — a single cross-attention step cannot bridge both.
Proposed — MRSeg
❄️
Frozen Backbones + LoRA
ConvNeXt-Tiny + PubMedBERT. LoRA on later stages; normalization trainable. Pretrained priors preserved.
🔀
Pair Adapter
Router derives sparse route α from GAP(f₄) + Mean(t). Same α controls 3 separate adapter banks for t, f₃, f₄ — shared route, feature-specific params.
🗺️
Region Bridge
Text queries aggregate dense visual tokens → latent regions → self-attn + text cross-attn → zero-init residual back to feature map.
