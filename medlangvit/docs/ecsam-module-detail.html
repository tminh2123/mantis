MedLangViT — Module Detail

ECSAM — Enhanced Channel-Spatial Attention

Input X ∈ ℝ^{B×C×H×W} = DownCNN features + Reconstructed UpViT features (element-wise add)

ECSAM INNOVATION
① Channel Self-Attention
Shared QK projection — 1 Conv 1×1 tạo cả Q và K, giảm params so với 2 conv riêng. Sau đó V từ conv riêng. Dot-product Q⊗K tạo channel correlation matrix, normalize bằng softmax. Áp dụng lên V → V'_low, rồi GroupConv restore về C channels → V'.
A = softmax(Q ⊗ K) V'_low = A ⊗ V → V' = GroupConv(V'_low) V' ∈ ℝ^{B×C×H×W}
Khác SE Block: SE dùng GlobalAvgPool tĩnh. ECSAM dùng self-attention học dynamic relationships giữa channels.
GIỐNG CBAM SPATIAL
② Spatial Attention — SAM
Cơ chế y hệt spatial attention của CBAM. AvgPool và MaxPool trên chiều channel của V', concat thành 2×H×W, qua Conv k×k → sigmoid → spatial mask S ∈ [0,1].
avg = AvgPool(V'), max = MaxPool(V') S = σ(Convk×k(concat(avg, max))) X' = V' ⊙ S
Điểm khác so với CBAM: SAM nhận V' từ self-attention channel (dynamic) thay vì V' từ SE-style channel attention (static). Input tốt hơn → output spatial mask tốt hơn.
DESIGN CHOICE
③ Learnable γ Residual
γ ∈ ℝ^{1×C×1×1} là per-channel scale, khởi tạo = 0. Lúc đầu training, output = X (identity). γ dần học mức đóng góp của attention. Giúp training ổn định, tránh attention gây nhiễu ngay từ đầu.
O = γ ⊙ X' + X γ init = 0 → O = X at start
