Medical Image Segmentation

C2Seg Architecture

Consistency-enhanced Two-stage Segmentation model for medical image analysis. These diagrams document the implementation synced with the c2seg-origin paper.

Level 1

Overall Architecture

End-to-end view showing Visual Encoder, Language Encoder, BCAM fusion modules, Decoder with PixLevelModule, and Deep Supervision outputs.

Level 2

Component Details

Detailed architecture of BCAM module, K-Gate (KAN-based gating), PixLevelModule attention, and multi-scale loss functions with asymmetric weights.

Training

Training Stages

Two-stage training pipeline: Stage I CaCL pretraining for cross-modal alignment, Stage II segmentation fine-tuning with deep supervision loss.

Technical Stack

Visual Encoder: 5× DownBlock (Conv)
Language Encoder: CLIP ViT-B/32 (frozen)
Fusion: BCAM × 4 + K-Gate (KAN)
Decoder: 4× UpBlock + PixLevelModule
Loss (Stage I): CaCL (τ=0.07, ε=0.8)
Loss (Stage II): DeepSupervision × 5 scales
Input Size: 224×224×3
Output: 224×224×1 (mask)

Implementation: models/c2seg.py · models/losses.py · run.py
